# News Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a seeded bilingual News entity and render its records on `News/Index`.

**Architecture:** Add `News` under `Entities`, a repository/service/view-model/controller flow matching the requested layering, and a separate seed-data class consumed by `ApplicationDbContext`. The view renders bilingual database content and existing `site.js` language events switch it without duplicating page markup.

**Tech Stack:** ASP.NET Core MVC, Razor Views, EF Core SQL Server, vanilla JavaScript.

**Spec:** `docs/superpowers/specs/2026-10-05-news-design.md`

## Global Constraints

- Preserve the current MVC architecture and existing static News actions.
- Use `BaseModel` audit fields and async EF Core APIs.
- New visible UI labels require matching `vi` and `en` keys in `wwwroot/js/site.js`.
- Do not add NuGet packages or change authentication/configuration.

## Review Focus

- Empty or malformed seed links must not break rendering: seed links are valid absolute URLs.
- News ordering must be deterministic: newest `PublishedAt`, then `TitleVi`.
- Switching language must update dynamic database-backed title/content immediately.

### Task 1: Data and persistence

**Files:** Create `Entities/News.cs`, `Data/NewsSeedData.cs`, `Repository/INewsRepository.cs`, `Repository/NewsRepository.cs`; modify `Data/ApplicationDbContext.cs`.

- Define the exact bilingual fields and EF constraints.
- Add `DbSet<News>` and `HasData(NewsSeedData.Items)`.
- Implement `GetAllAsync(CancellationToken)` using `AsNoTracking`, descending `PublishedAt`, then `TitleVi`.

### Task 2: Service and endpoint

**Files:** Create `ViewModels/NewsViewModel.cs`, `Services/INewsService.cs`, `Services/NewsService.cs`; modify `Controllers/NewsController.cs` and `Program.cs`.

- Map all display fields from repository entities to view models.
- Add `Index(CancellationToken)` and register repository/service with DI.

### Task 3: Razor UI and translations

**Files:** Create `Views/News/Index.cshtml`; modify `Views/Shared/_Layout.cshtml`, `wwwroot/js/site.js`, and `wwwroot/css/site.css` only as needed.

- Add bilingual static labels and dynamic content attributes.
- Add an Index navigation link and language-change rendering for cards.

### Task 4: Schema verification

**Files:** Create an EF migration through the existing EF tooling.

- Verify the model, migration, build, and available test command.
